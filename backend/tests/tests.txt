ONE-TIME DATABASE SETUP (only needed once per machine)
----------------------------------------------------------
1. Create the test database, owned by the app user:

python -c "
import psycopg2
conn = psycopg2.connect(host='localhost', port=5432, user='postgres', password='YOUR_SUPERUSER_PASSWORD', dbname='postgres')
conn.autocommit = True
cur = conn.cursor()
cur.execute('CREATE DATABASE tru_connect_test OWNER tru_connect_app')
print('DATABASE CREATED')
conn.close()
"

2. Create the 8 schemas:

python -c "
import psycopg2
conn = psycopg2.connect(host='localhost', port=5432, user='tru_connect_app', password='YOUR_APP_PASSWORD', dbname='tru_connect_test')
conn.autocommit = True
cur = conn.cursor()
for schema in ['auth', 'business', 'marketplace', 'platform', 'supplier', 'trust', 'verification', 'security']:
    cur.execute(f'CREATE SCHEMA IF NOT EXISTS {schema} AUTHORIZATION tru_connect_app')
print('SCHEMAS CREATED')
conn.close()
"

3. Apply every migration (creates tables AND the append-only trigger):

$env:DATABASE_URL = "postgresql+psycopg2://tru_connect_app:YOUR_APP_PASSWORD@localhost:5432/tru_connect_test"
