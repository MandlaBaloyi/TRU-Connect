# `storefront/`

The six merchandising sections on a supplier profile: on sale, best sellers,
new arrivals, better-per-unit-in-bulk, the supplier pick, and curated shelves.

Four are computed by the platform; two the supplier chooses.

Already built and working on mobile — this is the web editor for the same
configuration. Read the backend service first
(`network/connections/services/storefront/`) rather than inventing rules.
